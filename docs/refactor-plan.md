## 🔴 Críticos — travam confiabilidade do pacote

### ✅ C1. Remoção silenciosa de campos no `getDMMFSafe` — FEITO
- **Onde:** [src/main.ts:70-105](../src/main.ts)
- **Problema:** Quando o DMMF falha por tipo desconhecido, o código apaga as linhas do campo via regex e tenta de novo, sem avisar o usuário. Se um enum customizado compartilhar nome com um tipo builtin, ele é removido incorretamente.
- **Por que importa:** Perda silenciosa de dados de schema → DTOs gerados sem campos que existem no banco. É o pior tipo de bug num gerador de código: o build passa.
- **Ação:** ✅
  1. ✅ Coletar os tipos faltantes numa lista.
  2. ✅ Por padrão lança erro detalhado com lista de tipos e nome do schema externo em que aparecem.
  3. ✅ Flag `--allow-missing-types` faz opt-in do comportamento antigo (com `console.warn` destacado por schema).
  4. ✅ `Helper.escapeRegex` aplicado a cada tipo antes de compor o pattern.
- **Esforço:** 🟡

### 🟨 C2. Geração de código por `string` concat sem validação — PARCIAL
- **Ação:**
  1. ✅ [src/utils/ts-validator.ts](../src/utils/ts-validator.ts): `ts.transpileModule` roda em cada `.ts` gerado antes do prettier. Falha com erro que inclui filepath, linha/coluna e mensagem. TypeScript carregado lazy (opcional como peer).
  2. 🟨 Snapshot tests de fluxo ponta-a-ponta: adiado — requer fixture project. L6 cobriu unit tests das partes puras.
  3. ⏸ Migração AST (`ts-morph`) — Sprint 4.

### ✅ C3. Dependência de `@prisma/internals` — FEITO (itens 1-3)
- **Onde:** [src/utils/dmmf.ts](../src/utils/dmmf.ts) (novo), [package.json](../package.json), [README.md](../README.md)
- **Ação:** ✅
  1. ✅ Versão pinada exata: `"@prisma/internals": "7.0.0"`.
  2. ✅ Seção "Known Limitations" adicionada ao README alertando sobre o risco.
  3. ✅ Uso isolado em `src/utils/dmmf.ts` — main.ts não importa mais diretamente do `@prisma/internals`. Trocar por alternativa no futuro mexe só nesse arquivo.
  4. ⏸ Avaliar `@mrleebo/prisma-ast` como alternativa — pendente (Sprint 4).

### ✅ M1. God class `DocGenModel` — FEITO

- Tests cobrem `InputNamespaceBuilder` e `buildModelNamespace` ([namespace-builder.test.ts](../src/__tests__/namespace-builder.test.ts)).

### ✅ M4. Erros silenciados — FEITO
- **Ação:**
  1. ✅ `console.warn` sobre validators vazios removido.

  3. ✅ [main.ts](../src/main.ts): `run()` com `.catch`; narrow `instanceof Error`; `DEBUG=1` ou `--debug` imprime stack.

### 🟨 M5. Fetch de schemas externos sem robustez — MAIORIA FEITA
- **Ação:**
  1. ✅ `AbortController` com timeout de 30s em [prisma-utils.ts](../src/utils/prisma-utils.ts).
  2. ✅ Retry com backoff exponencial (2 retries, 1s→2s). Erros de shape (`SchemaShapeError`) não re-tentam.
  3. ⏸ Regex `datasource`/`generator` em [main.ts](../src/main.ts): mantida. Substituir por parser linha-a-linha é risco por pouco ganho — fica para quando aparecer um caso real que quebre.
  4. ✅ Fail-fast por padrão; `--continue-on-fetch-error` restaura o comportamento antigo.
  5. ⏸ Cache em disco: não implementado. Nice-to-have, pular.
